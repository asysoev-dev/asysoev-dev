## Проекты

### SkillDev
Портфолио-сайт с собственным SSR на Express + Vue, с бэкендом на Node.js и PostgreSQL, WebSocket, JWT-авторизацией и CRUD-админкой. Деплой через Docker Compose и GitHub Actions.

Демо-разделы: таблица на 140 лидов с фильтрами и экспортом, графики на Chart.js, счётчик онлайн через socket.io, витрина UI-кита, форма входа, личный кабинет.
